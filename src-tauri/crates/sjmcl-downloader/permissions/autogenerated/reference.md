## Default Permission

download engine commands

#### This default permission set includes the following:

- `allow-submit-group`
- `allow-pause-group`
- `allow-resume-group`
- `allow-cancel-group`
- `allow-retry-group`
- `allow-remove-group`
- `allow-snapshot`
- `allow-list-tasks`
