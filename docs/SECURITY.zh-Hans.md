## 报告安全漏洞

如果你认为在我们的启动器中发现了安全漏洞，请按照以下步骤向我们报告：

1. **请勿**为安全漏洞创建 GitHub 议题
2. 发送邮件至 [launcher@sjmc.club](mailto:launcher@sjmc.club)
   - 邮件主题请以 `[SJMCL Security]` 开头
   - 请尽可能提供有关该漏洞的详细信息

## 响应时间

我们会在中国工作日期间定期查看安全邮箱。通常情况下，你可以在 2 至 3 个工作日内收到初步回复。

## 后续流程

- 我们会确认已经收到你的漏洞报告
- 我们会展开调查，并向你提供调查结果的最新信息
- 我们会及时告知你修复工作的进展
- 问题解决后，我们可能会邀请你对解决方案提供反馈

感谢你帮助我们维护启动器的安全！
